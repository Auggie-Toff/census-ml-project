# 📊 Census Data Analysis & Machine Learning

This project demonstrates a full **data science & machine learning pipeline** using a **Census dataset**.  
It covers **descriptive statistics, association rules, regression, classification, and clustering**.

---

## 🚀 Highlights
- **Descriptive Analysis**: Summarized key demographic and economic trends
- **Regression Models**: Predicted numeric outcomes (e.g., income, age-related attributes)
- **Classification Models**: Predicted categorical variables using ML (Logistic Regression, Decision Trees, Random Forest, etc.)
- **Clustering**: Applied unsupervised ML to identify population segments
- **Association Rule Mining**: Discovered frequent patterns in census attributes

## ▶️ How to Run
1. Open Jupyter:
```bash
pip install jupyter
jupyter notebook
```
2. Explore the notebooks in the following order:
   - `Descriptive_Analysis.ipynb`
   - `Regression.ipynb`
   - `Classification.ipynb`
   - `Clustering.ipynb`
   - `Association_Rule_Mining.ipynb`
